The hosted checkout is wired to Stripe but the server is missing its keys. The local product is complete and free — run it on your machine right now.

For the operator

Set the following environment variables on the checkout backend (see site/checkout_server.py) and restart it:

  • STRIPE_SECRET_KEY — sk_live_...<\/code> or sk_test_...<\/code>
  • STRIPE_PRICE_PRO — Stripe price id for the Pro tier ($9/mo)
  • STRIPE_PRICE_TEAM — Stripe price id for the Team tier ($99/mo)

Optional: STRIPE_SUCCESS_URL, STRIPE_CANCEL_URL.
