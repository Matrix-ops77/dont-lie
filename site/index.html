Don't-Lie

A local-first signed receipt vault for OpenAI- and Anthropic-compatible AI calls. MIT-licensed. You operate the key. You verify offline on a clean machine.

Install

python -m pip install https://github.com/Matrix-ops77/dont-lie/releases/download/v0.3.8/dontlie-0.3.8-py3-none-any.whl
dontlie --version
dontlie demo            # 30-second offline proof
dontlie web             # local HTTP UI on a port you pick

That's it. No account, no Docker, no cloud, no environment variables you must set. The CLI and the passive SDK launcher land on $PATH.

What you get in 5 minutes

  1. The GitHub release wheel lands the CLI, the dontlie-passive launcher, and the OpenAI / Anthropic SDK patches. PyPI publication is not configured yet.
  2. eval $(dontlie-passive) in your shell — every detected SDK now routes through the local proxy.
  3. Your next call lands in a SQLite vault you control, signed with an Ed25519 key you generated, hash-linked to the receipt before it.
  4. dontlie verify walks the chain in 0.4s. A tampered receipt fails with payload sha256 mismatch + signature verification failed.
  5. dontlie export --bundle bundle.json gives outside counsel a portable, self-contained file. They verify it in 0.8s on a clean laptop with no Don't-Lie install needed.

What a receipt proves

Local integrity

The signed bytes are byte-for-byte what crossed the wire. A locally mutated receipt breaks verification.

Chain continuity

Each receipt hash-links to the previous one. Delete or insert a row in the middle and the chain breaks.

Signer

The bundle embeds the public keys. Pin a key externally to prove the bundle was authored by a key you trust.

Provider route

The receipt records the model name, endpoint, and raw response body up to 16 MiB.

What a receipt does not prove

This is the honest list, called out before you buy:

That the model was truthful.

Receipts record what the model said. They do not judge whether it was correct. Hallucinations are recorded faithfully; that is the point.

That the upstream provider is who it claims to be.

The local proxy can record model=gpt-4o but cannot independently attest that the upstream service is actually OpenAI. Trust the provider separately.

Which person or organization held the signing key.

The receipt proves a key signed it. It does not prove who held that key. Use external key pinning for that.

Resistance to an attacker who already has the key.

An attacker who holds the private key can forge new receipts that chain into history. Once a key is revoked, receipts signed after revocation fail verification.

Content semantics beyond the bytes.

The receipt binds bytes. It does not interpret them.

How it works in one line

Point any OpenAI- or Anthropic-compatible client at the local proxy on a port you choose. The proxy forwards the request to your provider and signs the response into a SQLite vault. Offline verification needs no private key, no Don't-Lie install, and no network.

What is not in this release

  • No hosted service. There is no SaaS, no dashboard, no account, no cloud sync, no shared namespace, no team seats. v0.3.8 is a Python package you install and operate yourself.
  • No hosted witness. The optional dontlie witness-service notary runs as a process on hardware you control. It is not a public service.
  • No SOC 2 / HIPAA / GDPR / EU AI Act "compliance" claims. The operator reference memos in the repository are explicit informational material. They tell an operator what a receipt does and does not cover for each regime. They are not certifications, and they are not legal advice.
  • No paid tiers, no checkout, no subscription, no billing.

When (and only if) a hosted service ever ships, it will be a separate product with its own name, its own terms, and its own page. It will not retroactively change the MIT-licensed local-first product.

Limits (current release)

  • v2 receipt chain only. v0.1.x receipts are still verifiable and upgrade on append.
  • Single-machine key. Cross-machine reconciliation uses exported bundles and pinned keys.
  • Streaming responses are reconstructed from the final chunk; the full raw SSE body is stored alongside (up to 16 MiB by default).
  • The proxy is OpenAI- and Anthropic-Messages-compatible. Other provider shapes need a small adapter.
No phone home. Every core CLI command makes zero outbound network calls. The No-Phone-Home Pledge is enforced by test_phone_home.py in CI.
